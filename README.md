# Active eD2k Server List

<p>
  <img src="https://upload.wikimedia.org/wikipedia/commons/4/4a/EMule_mascot.svg" alt="eMule" width="70">
</p>

An automated eD2k (eMule/eDonkey) server list generator. 

This project uses **GitHub Actions** to probe known eDonkey servers via UDP and **GitHub Pages** to host a live, auto-updating `server.met` file alongside a responsive web directory.
